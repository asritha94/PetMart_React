# PetMart - Updated React Frontend

## Updated navigation
- Home
- Categories
- About
- Contact
- Wishlist, Cart, Login/Register and Admin remain available through their existing actions.
- Separate Pets and Shop pages/navigation have been removed.

## Categories
The Categories section contains exactly 10 categories:
1. Dogs
2. Cats
3. Birds
4. Fish
5. Rabbits
6. Small Pets
7. Pet Food
8. Accessories
9. Grooming
10. Toys

Each category has exactly 4 starter products/items.

## Run
Open this folder in VS Code/terminal:

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

If an older PetMart version was previously opened in the same browser, refresh/clear the site's localStorage if old catalog data appears. The app catalog migration version is incremented to refresh the starter catalog.
